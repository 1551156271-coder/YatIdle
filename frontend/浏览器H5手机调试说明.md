# 浏览器 H5 手机调试说明

## 正确启动顺序

1. 启动 MySQL。
2. 启动后端 Spring Boot，确认端口为 `8080`。
3. 启动 HBuilderX/H5/Vite 前端。
4. 从 Vite `Network` 地址中选择手机能访问的电脑局域网 IP，例如 `http://172.18.156.250:5173/`。

## 手机端接口检查

手机浏览器先打开：

```text
http://172.18.156.250:8080/api/categories
```

能看到 JSON 才说明后端可以被手机访问。当前 H5 前端会根据页面访问地址自动把接口请求推导到同一个主机的 `8080` 端口，例如：

```text
http://172.18.156.250:5173/ -> http://172.18.156.250:8080/
```

## 后端配置建议

本地调试示例配置见：

```text
backend/src/main/resources/application.example.properties
```

手机浏览器访问电脑后端时，建议确认：

```properties
server.port=8080
server.address=0.0.0.0
app.base-url=http://电脑局域网IP:8080
```

不要把自己的真实 `application.properties` 提交到 Git。

## 常见失败原因

- 前端页面打开了，但接口仍请求 `127.0.0.1:8080`。
- 电脑和手机不在同一个 Wi-Fi。
- Windows 防火墙拦截 Java 或 8080 入站连接。
- Vite Network 地址选中了 Docker、WSL、VPN、热点或虚拟网卡 IP。
- 后端没有用 `server.address=0.0.0.0` 监听局域网。
- 后端返回的图片 URL 带 `localhost` 或 `127.0.0.1`，手机无法访问。

## 验证清单

- 手机能打开 `http://电脑局域网IP:5173/`。
- 手机能打开 `http://电脑局域网IP:8080/api/categories`。
- 首页商品、求购列表和搜索结果能加载真实数据。
- 商品图片、头像和聊天/商品/头像上传接口都走 `http://电脑局域网IP:8080`。
- 关闭后端后，首页、求购页、搜索页显示网络失败卡片和重试按钮，而不是误显示为空数据。
