# 订单模块测试用例

| 用例ID | 测试标题 | 前置条件 | 测试步骤 | 测试数据 | 预期结果 | 优先级 |
|---|---|---|---|---|---|---|
| ORDER-001 | 下单成功 | 用户已登录，商品在售 | 选择商品点击购买按钮 | 无 | 显示下单成功，进入交易页面 | P0 |
| ORDER-002 | 库存不足时下单 | 库存为0或已被他人购买 | 点击下单已售罄的商品 | 商品ID：123 | 购买按钮置灰，提示“商品已售罄”| P0 |
| ORDER-003 | 购买自己发布的商品 | 用户已登录且有已发布商品 | 进入自己发布的商品信息界面并点击购买按钮 | 无 | 购买按钮置灰 | P1 |
| ORDER-004 | 向卖家发起咨询 | 用户已登录 | 进入商品详情页，点击下方咨询按钮 | 无 | 跳转聊天界面 | P1 |
| ORDER-005 | 将商品收藏进心愿单 | 用户已登录 | 进入商品详情页，点击下方收藏按钮（空心爱心）| 商品ID：123 | 空心爱心变实心，商品出现在心愿单中 | P2 |
| ORDER-006 | 商品取消收藏 | 用户已登录，商品已收藏 | 进入商品详情页，点击下方收藏按钮（实心爱心）| 商品ID：123 | 实心爱心变空心，商品从心愿单中移除 | P2 |
| ORDER-007 | 查看卖家主页 | 用户已登录 | 点击卖家头像 | 卖家
