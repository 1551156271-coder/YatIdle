# 我的发布模块测试用例

| 用例ID | 测试标题 | 前置条件 | 测试步骤 | 测试数据 | 预期结果 | 优先级 |
|---|---|---|---|---|---|---|
| MyListings-001 | 显示用户已发布商品列表 | 用户已登录，已发布商品 | 1.进入个人中心 2.点击"我的发布"或"发布" | 无 | 显示用户发布的所有商品列表，包含商品图片、名称、价格、状态 | P0 |
| MyListings-002 | 商品显示在售状态 | 用户有在售商品 | 1.查看发布列表中的商品卡片 | 商品状态：在售 | 商品卡片显示"在售"绿色标签 | P0 |
| MyListings-003 | 商品显示已售状态 | 用户有已售出商品 | 1.查看发布列表中的商品卡片 | 商品状态：已售出 | 商品卡片显示"已售出"灰色标签，商品图片变灰 | P0 |
| MyListings-004 | 商品显示下架状态 | 用户有已下架商品 | 1.查看发布列表中的商品卡片 | 商品状态：已下架 | 商品卡片显示"已下架"标签，商品图片变灰 | P0 |
| MyListings-005 | 点击商品进入详情 | 我的发布列表已加载 | 1.点击任一商品卡片 | 商品：iPhone 13 | 跳转至商品详情页，显示商品完整信息 | P0 |
| MyListings-006 | 编辑商品信息 | 商品详情页打开，商品在售 | 1.点击编辑按钮或右上角菜单中的"编辑" | 无 | 进入商品编辑页面，显示原商品信息，可修改名称、价格、描述等 | P1 |
| MyListings-007 | 删除/下架商品 | 商品详情页打开 | 1.点击右上角菜单 2.选择"下架"或"删除" | 无 | 显示确认对话框，确认后商品状态变为下架，从发布列表中移除 | P1 |
| MyListings-008 | 重新上架已下架商品 | 商品详情页打开，商品已下架 | 1.点击"重新上架"按钮 | 无 | 商品状态变为在售，回到发布列表中 | P1 |
| MyListings-009 | 发布列表为空提示 | 用户未发布任何商品 | 1.进入我的发布页面 | 无 | 显示空态提示："您还没有发布任何商品"，显示"立即发布"按钮 | P1 |
| MyListings-010 | 点击发布新商品按钮 | 我的发布页面已打开 | 1.点击"立即发布"或"发布新商品"按钮 | 无 | 跳转至发布类型选择页面或直接进入发布表单 | P0 |
| MyListings-011 | 统计已售商品数量 | 用户有已售出商品 | 1.查看页面统计信息或个人中心 | 无 | 准确显示已售商品的数量统计 | P2 |
| MyListings-012 | 上拉加载更多已发布商品 | 发布列表已加载至底部 | 1.向上滑动列表至底部 2.持续上拉 | 无 | 显示加载更多动画，新的商品卡片追加到列表 | P2 |
