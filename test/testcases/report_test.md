# 举报模块测试用例

| 用例ID | 测试标题 | 前置条件 | 测试步骤 | 测试数据 | 预期结果 | 优先级 |
|---|---|---|---|---|---|---|
| Report-001 | 举报页面加载显示表单 | 用户已登录，打开举报页面 | 1.打开举报页面 | 无 | 显示举报原因选择、详细描述输入框、截图上传区域、提交按钮 | P0 |
| Report-002 | 选择举报原因 | 举报表单已打开 | 1.点击"虚假商品"选项 | 举报原因：虚假商品 | 该选项被选中（显示为勾选状态） | P0 |
| Report-003 | 举报原因单选限制 | 举报表单已打开，已选择一个原因 | 1.选择"虚假商品" 2.再点击"恶意欺诈" | 无 | 仅"恶意欺诈"保持选中，"虚假商品"取消选中 | P1 |
| Report-004 | 举报原因列表包含常见类型 | 举报表单已打开 | 1.查看举报原因列表 | 无 | 显示"虚假商品"、"恶意欺诈"、"违禁品"、"不雅信息"等常见原因 | P0 |
| Report-005 | 输入详细描述 | 举报表单已打开 | 1.点击详细描述输入框 2.输入描述文本 | 描述：该商品描述与实物严重不符 | 显示输入内容和字数计数器 | P0 |
| Report-006 | 描述字数限制 | 举报表单已打开 | 1.尝试输入超过1000字的描述 | 超长描述文本 | 不允许输入超过限制字符或显示"描述长度不能超过1000字"提示 | P1 |
| Report-007 | 上传举报截图 | 举报表单已打开 | 1.点击截图上传区域 2.选择本地图片 | 截图文件：screenshot.jpg | 图片预览显示，显示上传进度 | P0 |
| Report-008 | 上传多张截图 | 举报表单已打开 | 1.点击上传区域 2.依次上传4张截图 | 截图文件×4 | 依次显示4张图片预览，可删除单张 | P0 |
| Report-009 | 截图上传数量限制 | 已上传4张截图 | 1.尝试上传第5张截图 | 截图文件：screenshot5.jpg | 不允许上传超过4张或显示"最多只能上传4张截图"提示 | P1 |
| Report-010 | 删除已上传截图 | 已上传截图 | 1.点击截图预览上的删除按钮（X） | 无 | 截图从预览列表中移除 | P1 |
| Report-011 | 缺少必填项提交失败 | 举报表单填写不完整 | 1.不选择举报原因 2.不输入描述 3.点击提交 | 无 | 显示"请选择举报原因"和"请输入详细描述"等错误提示 | P1 |
| Report-012 | 提交举报成功 | 举报表单已完整填写 | 1.填写所有必填项 2.点击"提交举报"按钮 | 完整举报信息 | 显示加载动画，成功后显示"举报成功，感谢您的反馈"提示，返回上级页面 | P0 |
| Report-013 | 举报后表单清空 | 举报提交成功后返回 | 1.再次打开举报页面 | 无 | 表单已清空，恢复初始状态（不显示之前填写的信息） | P2 |
