# 后台管理运行说明

如果组员在自己的电脑上运行后台管理系统，需要先准备数据库，并创建一个管理员账号。

## 1. 初始化数据库

先创建并初始化项目数据库，执行后端的数据库脚本：

```sql
SOURCE backend/db/schema.sql;
```

也可以在 MySQL 客户端中打开 `backend/db/schema.sql`，直接执行整个脚本。

## 2. 创建管理员账号

后台管理员不是单独的表，而是 `user` 表中的用户。只要用户的 `role = 1`，就拥有管理员权限。

可以直接插入一个默认管理员账号：

```sql
USE yatidle;

INSERT INTO user (
  username,
  password,
  nickname,
  role,
  status,
  credit_score,
  balance
) VALUES (
  'admin',
  'admin',
  '管理员',
  1,
  'active',
  100,
  10000.00
);
```

然后后台登录使用：

```text
账号：admin
密码：admin
```

## 3. 把已有用户设为管理员

如果已经有普通用户，也可以直接把这个用户升级成管理员：

```sql
USE yatidle;

UPDATE user
SET role = 1, status = 'active'
WHERE username = '用户的登录名';
```

之后使用该用户原本的密码登录后台即可。

## 说明

后台登录会检查两个条件：

- 用户状态必须是 `active`
- 用户角色必须是 `role = 1`

后端启动时会自动补充部分后台管理需要的表，例如操作日志表，但不会自动创建管理员账号，所以第一次运行时需要手动创建或升级一个管理员账号。

## 4. 启动后端

后端是 Spring Boot 项目，目录在：

```text
backend/
```

可以用 IDEA 打开项目，然后运行后端启动类。

也可以在命令行进入后端目录后运行：

```bash
cd backend
mvn spring-boot:run
```

后端默认接口地址是：

```text
http://127.0.0.1:8080
```

管理后台前端会请求这个地址，所以后端需要先启动成功。

## 5. 启动管理后台前端

管理后台前端是 uni-app H5 项目，目录在：

```text
admin/
```

这个目录没有 `package.json`，不是用 `npm run dev` 启动，建议用 HBuilderX 运行：

1. 打开 HBuilderX
2. 选择“文件” -> “导入” -> “从本地目录导入”
3. 选择项目里的 `admin/` 目录
4. 选择“运行” -> “运行到浏览器” -> Chrome 或其他浏览器

启动后打开管理后台页面，使用管理员账号登录：

```text
账号：admin
密码：admin
```

如果需要运行普通用户端，则同样用 HBuilderX 导入：

```text
frontend/
```

然后运行到浏览器或小程序模拟器即可。
